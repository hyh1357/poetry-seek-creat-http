# 诗词 - 古典诗词鉴赏与创作平台

一个优雅的古典诗词鉴赏与创作 Web 应用，包含 5000 首精选诗词、名句搜索、AI 创作助手等功能。

## 功能特性

- 📖 **诗词鉴赏** — 5000 首精选诗词，包含翻译、鉴赏、创作背景
- 💬 **名句检索** — 按主题、作者、朝代筛选经典名句
- 👤 **作者档案** — 200+ 位诗人详细生平与作品全集
- ✍️ **诗词创作** — 内置创作编辑器，可保存个人作品
- 🤖 **AI 创作助手** — 支持 DeepSeek API，可续写、润色、点评（可选）

## 快速开始

直接用浏览器打开 `index.html` 即可使用（纯前端应用，无需后端）。

## AI 助手（可选）

1. 点击顶部导航「AI 助手」
2. 打开右上角 AI 开关
3. 输入你的 [DeepSeek API Key](https://platform.deepseek.com/)
4. 开始与 AI 讨论诗词创作

不输入 API Key 也可使用本地规则引擎。
